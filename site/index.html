EvoLua

A self-evolving digital organism. It perceives the machine it runs on, makes sense of what it sees, grows its own plugins under honest selection pressure, finds its own brain, and replicates into a colony — then reports back.

What it does

The Rust host never changes and lua/core/ is an immutable contract. Every new capability is a new .lua file — written by the organism itself, at runtime, from genome blueprints or by its brain.

1 · PERCEPTION

Sharp senses, a world model

Per-process CPU and RAM, OS crash and error logs, the filesystem. Entities get dossiers: temperature, trend, salience.

2 · BRAIN

Reasons with whatever it can reach

An online service, a model already on the machine, or a download sized to the host — with online ↔ local failover for life. Rules when there is no brain.

3 · AUTONOMY

Learn → report → suggest → act

A five-rung ladder with a file-based approval inbox, a safe-list, reversibility and an audit log. Destructive actions always wait for a human.

4 · EVOLUTION

A real genetic system

Typed-rule genomes, honest fitness derived from observable facts, MAP-Elites diversity, tournament selection, self-adaptive mutation, gene transfer.

5 · COLONY

Replicates, with purpose

Bounded self-replication into communicating processes, across machines with a mesh. Offspring are born with a crystallized goal; the colony learns which purposes pay.

6 · SYNTHESIS

The brain writes organs

Templates are the floor. For a goal nothing covers, the model writes a whole organ against real command output, pre-flighted column by column, then selection decides.

The brain is found, not shipped

The binary carries no model and weighs about 6 MB. At birth the organism picks a brain in this order and keeps failing over between them:

  1. An explicit GGUF (--model, $EVOLUA_MODEL).
  2. An online service whose key is in the environment or in keys/<provider> — free tiers first.
  3. The biggest usable brain already on the machine: Ollama, LM Studio, Hugging Face cache GGUFs, a running local server, the macOS on-device model.
  4. The keyless public endpoint, then a pinned download sized to the host, then rules.

A blocked network never stalls the loop: after three failures the online brain backs off, the local one answers, a probe brings the service back and frees the local model's RAM. No key anywhere? It writes a one-page request naming the free providers and picks the key up the moment it appears.

Every switch is judged on fresh samples and rolled back if the new brain does worse. A brain too slow for the host steps down. Verdicts are remembered across lives.

A colony, across machines

One seeded organ gives the organism a sense of siblings through a plain file protocol: presence beacons, mailboxes, a shared gene pool and a purpose ledger. With --mesh a small host-side nerve carries the same files over the network — LAN discovery, seeds for Tailscale or WAN — so a peer on another machine looks exactly like a local one.

Replication is triply bounded: clone depth, colony size and a colony-wide cooldown. Children are mortal and never replicate themselves. A node without a brain can borrow a peer's served model; a node without internet can tunnel through a peer's gateway.

Quick start

# build the single binary (Lua is vendored; no model bytes inside)
cargo build --release

./target/release/evolua --ticks 60 --tick-seconds 0.2      # bounded fast demo
./target/release/evolua --goal "report errors"             # directed mode (Turkish works too)
./target/release/evolua --clone --clone-ignore-battery     # let it grow a colony
./target/release/evolua --mesh --mesh-seed host:7707       # join organisms on other machines
./target/release/evolua                                    # lives indefinitely

# no Rust toolchain? a stock Lua 5.3+ runs the organism directly (rules-only brain)
lua lua/main.lua --ticks 60 --tick-seconds 0.2

Then read the data home it printed: reports/ for Markdown status reports, plugins/ for the organs it wrote, state/evolution.log for the per-generation metrics, approvals/ for anything it wants a human to decide.
